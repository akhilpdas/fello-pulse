# API contract changes

The machine-readable contract (`specs/001-…/contracts/openapi.yaml`) is regenerated by
`python3 -m pulse.openapi_export` and guarded by the drift test; this is the human-readable delta.

## Authentication (new)

| Route | Auth | Notes |
|---|---|---|
| `POST /auth/login` `{workspace, email, password}` | none | 200 sets the session cookie, returns `{user:{id,name,role}, tenant:{id,slug}}`. 401 identical for unknown workspace/email/wrong password. 429 when limited. |
| `POST /auth/logout` | session | revokes the session, clears the cookie |
| `GET /auth/me` | session | `{user, tenant}`; the UI uses it to decide whether to show the sign-in form |
| `POST /admin/users` `{email,name,role,password}` | operator | create a user in the caller's tenant |
| `PATCH /admin/users/{id}` `{role?, disabled?, password?}` | operator | takes effect on that user's next request |
| `GET /admin/audit` | operator | recent audit events |

## Every existing data route (changed)

- `X-Tenant-Id` / `X-User-Id` are **no longer read**. Sending them has no effect; a value that disagrees
  with the session writes a `tenant_mismatch` audit event.
- 401 without a valid session; 403 for a `csm` on operator routes.
- Queue, low-confidence, actions, account detail, evidence, score-diff: `csm` sees only
  `owner_user_id = self`; `operator` sees the tenant. A `csm` requesting an account they do not own gets **404**
  (not 403 — existence is not disclosed).
- `POST /actions/{id}/approve|reject|edit`: `actor_user_id` removed from the request body; the actor is the principal.

## Spec-001 gaps (new)

| Route | Notes |
|---|---|
| `POST /accounts/{id}/feedback` `{kind, note?}` | writes `feedback` (links the account's latest score). 201. |
| `POST /accounts/{id}/suppress` `{reason, expires_at}` | writes `suppression`; the account leaves the queue until expiry, scoring continues. 201. `DELETE /accounts/{id}/suppress` lifts it. |
| `GET /model` | gains `leave_one_tenant_out: [{tenant, auc, precision_at_capacity}]`. |

## Email (changed / new)

| Route | Notes |
|---|---|
| `POST /actions/{id}/approve` | response includes `state` ∈ {sent, send_failed, send_unconfirmed, not_configured, outbound_disabled, no_recipient, opted_out}, `state_reason`, `redirected_to`, `attempts`. Idempotent: a second call returns the first result. |
| `GET/PATCH /admin/outbound` | sender address, verified, enabled, demo_mode, test_inbox. Enabling is refused unless a verified sender exists. |
| `GET/POST/DELETE /admin/opt-outs` | operator-managed opt-out list. |

## Drafts (changed)

`GET /actions` rows gain `draft_source`, `draft_model`, `draft_fallback_reason`, and, when a human edited
it, `original_subject` / `original_body`.
